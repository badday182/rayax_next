# Каталог всех текстовых шаблонов и вариантов выбора (для локализации)

Этот файл — полная выгрузка всех украиноязычных строк, из которых сейчас собираются
отчёты в Rayax: названия зон, проекций, сторон, значения дропдаунов "Норма/Не норма"
и все под-поля деталей находок. Нужен как рабочая база для будущего перевода контента
на другие языки (не только интерфейса — см. обсуждение мультиязычности: сама ценность
приложения зашита именно в этих строках).

Источник — файлы в `src/data/**` по состоянию на текущий момент (ветка `main`). Список
не включает служебный код, только видимый пользователю/попадающий в отчёт текст.

**Важное про архитектуру, которое нужно учитывать при переводе:** значения из этих
массивов используются не только как подписи в дропдауне — по ним производится
точное сравнение строк (`.includes()`/`matches()`) в `FloatingLabel.js` и
`zoneInfoPattern.js`, чтобы решить, какой блок отчёта собирать. Простая замена текста
на перевод без правки этой логики сломает генерацию отчёта. Для локализации у каждого
такого значения фактически должен появиться отдельный "ключ" (как это уже сделано для
пользовательских кастомных вариантов — `fieldKeyByArray`/`matches()`), а видимый текст
должен подставляться по языку интерфейса, не как значение для сравнения.

## 2. Сквозные структурные элементы

Используются во многих зонах, не привязаны к конкретной зоне:

- **Сторона** (`sides.js`): `Справа`, `Зліва`, `Справа та зліва`
- **Норма/Не норма (общий бинарный вид)** (`normaNenorma.js`): `Норма`, `Не норма`
- **Проекція — ОГК** (`ogkViews.js`): `Оглядова`, `Пряма + права бічна`, `Пряма + ліва бічна`
- **Проекція — плечовий/кульшовий суглоб** (`plechovuyKulshovuySuglobViews.js`): `Пряма`, `В 2-х проекціях`
- **Констатация отсутствия костной травмы** (`kistkovaNorma.js`, переиспользуется как первый пункт "Норма/Не норма" почти во всех "простых" зон):
  `Грубих кістково-травматичних змін не визначається`
- **Сентинел "свій варіант"** (`svoiVaryant.js`): `Пустий варіант` — служебное значение "не печатать ничего, врач впишет текст вручную". Не подлежит переводу как обычный контент — это метка поведения, не диагностический текст. Присутствует почти во всех списках последним пунктом.

## 3. "Сложные" зоны с многосоставным отчётом: ОГК, ГВХ, ШВХ, ПВХ

У этих 4 зон верхний селектор "Норма/Не норма" — структурный: выбор конкретных
предустановленных строк определяет, какой блок ниже (детали находок) показывать
и какой JSX-шаблон общего "не норма" текста подставить. Пользователь также может
добавить свой собственный шаблон (заголовок + произвольное описание) — эта часть
не в этом каталоге, она пользовательские данные, а не встроенный контент.

## 5. Сводка объёма для оценки трудозатрат на перевод

- 19 зон обследования
- 4 "сложные" зоны с 7 под-полями каждая (28 под-полей, часть переиспользуется между зонами)
- ~15 "простых" зон с одним списком вариантов (в среднем 4-6 пунктов на зону)
- Итого уникальных предложений/фраз для перевода — порядка **150-180** строк не считая
  служебных (сторона/проекция/навигация), плюс сама UI-обвязка (кнопки, лейблы форм,
  сообщения об ошибках, `/account`, шапка сайта и т.д.), которая по объёму значительно
  меньше и типична для обычного i18n.
